# DWO-TEST

Kleiner Beispielshop zum Testen der Code-Analyse (DWO) von solcoda.

- `src/shop/pricing.py` – Netto, Mehrwertsteuer, Brutto (Beträge in Cent)
- `src/shop/invoice.py` – Rechnung aus Positionen, Anzeige in Euro
- `tests/` – `python -m unittest discover -s tests`
